Load it in Python

The vector file is word2vec text, which gensim reads directly: 

import gzip
from gensim.models import KeyedVectors

with gzip.open("sne_vectors.txt.gz", "rb") as raw:
    vectors = KeyedVectors.load_word2vec_format(raw, binary=False)

vectors.most_similar("AB002518.1.1416", topn=10)

What these files are

Formats and layout

sne_vectors.txt.gz — the 14,093 × 100 embedding, word2vec text, one OTU id per line. The ids are SILVA 138.2 accession numbers with the alignment span, the same form the OTU tables use.

dysbiosis_encoder.onnx and dysbiosis_embed.f16.bin — the classifier. The graph takes already-gathered 100-dimensional vectors, not token indices, because all thirteen fold checkpoints share one frozen embedding table and baking it into the graph would ship it thirteen times. Gather rows from the embedding blob with the indices in vocab.json, multiply by the rank-normalized abundance, and the graph does the rest.

traits_proba.f16.bin — the random forest's probability for every labelled OTU, on all classes of every trait, laid out as described in traits.json. This is what the confidence bands on the atlas are drawn from.

ref_scores.json — the 10,276 reference samples' model scores, split into controls and cases, sorted. This is the distribution the percentile is read from.
