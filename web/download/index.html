All data used by this site are static and publicly available. The embeddings can be loaded in Python, viewed in the TensorFlow Embedding Projector, or used directly as raw arrays.

Load the embeddings in Python

The vectors are provided in word2vec text format and can be loaded with gensim: 

import gzip
from gensim.models import KeyedVectors

with gzip.open("sne_vectors.txt.gz", "rb") as raw:
    vectors = KeyedVectors.load_word2vec_format(raw, binary=False)

vectors.most_similar("AB002518.1.1416", topn=10)

File descriptions

Formats and layout

sne_vectors.txt.gz: the 14,093 × 100 embedding matrix in word2vec text format, with one OTU per line. OTU identifiers are SILVA 138.2 accession numbers with the alignment span, as used in the OTU tables.

dysbiosis_encoder.onnx and dysbiosis_embed.f16.bin: the classifier. The ONNX graph takes 100-dimensional embedding vectors as input rather than token indices, because all 13 fold checkpoints share one frozen embedding table, which is stored separately. To run the model, select rows from the embedding table using the indices in vocab.json and multiply them by the rank-normalized abundances.

traits_proba.f16.bin: random forest probabilities for all classes of every trait, for each labelled OTU, in the layout described in traits.json. These values are used to draw the distribution plots in the atlas.

ref_scores.json: sorted model scores of the 10,276 reference samples, split into controls and cases. Percentiles are computed from this distribution.
